## How to Customize

1. **Update Contact Info**: Edit email, phone, LinkedIn, and GitHub links in footer, hero, and CTA sections
2. **Modify Projects**: Edit the projects array in `/components/projects.tsx`
3. **Update Skills**: Modify the skillCategories array in `/components/skills.tsx`
4. **Change Colors**: Update CSS variables in `globals.css`
5. **Edit Experience**: Update the experiences array in `/components/experience.tsx`
